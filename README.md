# Sales and Order Management System

## Project Description

A console-based Java application designed to simplify basic retail
operations, inventory management, and sales transaction recording.

The system provides separate administrator and customer functionalities
for managing products, stock, purchases, orders, and sales records.

## Proposed Features

### Administrator

-   Manage store information
-   Manage products and inventory
-   Manage customer orders
-   View sales records
-   Generate basic sales summaries

### Customer

-   Register and sign in
-   Browse products
-   Add items to a shopping cart
-   Checkout and place orders
-   View purchase history

## Project Objectives

1.  Simplify basic store operations.
2.  Organize inventory and product records.
3.  Record customer purchases and orders.
4.  Provide basic sales summaries.
5.  Apply Java programming concepts learned in IT 112.

## Technologies

-   Java
-   Console-based user interface
-   File handling for data persistence
